# CareerLens 공고 카드 제작 키트

이 폴더는 실제 채용공고를 CareerLens 카드 디자인으로 바꾸기 위한 독립 실행형 예시입니다. 인터넷 연결 없이도 카드 디자인과 글꼴을 확인할 수 있습니다.

## 학생이 사용하는 방법

1. ZIP 파일의 압축을 풉니다.
2. `index.html`을 Chrome으로 열어 두어스 예시가 정상적으로 보이는지 확인합니다.
3. 이 폴더 전체를 Codex 작업 폴더로 엽니다.
4. `STUDENT-PROMPT.txt`의 문장에 분석할 채용공고 URL을 넣어 Codex에 요청합니다.
5. 완성된 `index.html`을 확인하고 `인쇄 / PDF` 버튼으로 PDF를 저장합니다.

## 파일 구성

- `index.html`: 브라우저에서 여는 카드
- `card-data.js`: 카드에 표시할 모든 문구와 출처
- `styles.css`: 고정된 카드 디자인과 A4 인쇄 스타일
- `app.js`: 직접 편집, JSON 편집, 저장, 인쇄 기능
- `AGENTS.md`: Codex가 따라야 할 제작 규칙
- `CARD-GUIDE.md`: 항목별 작성 기준
- `STUDENT-PROMPT.txt`: Codex 요청문
- `doers-example.png`: 완성 예시 이미지
- `assets/fonts/`: 로컬 글꼴과 라이선스 고지
- `assets/logos/`: 기업 또는 서비스 로고

## 직접 수정

브라우저에서 `직접 편집`을 누르면 카드의 문구를 클릭해 수정할 수 있습니다. 많은 항목을 한 번에 바꾸려면 `JSON 편집`을 사용합니다. 구조화된 원본은 `card-data.js`이므로 새 카드를 만들 때는 이 파일을 기준으로 관리합니다.

## 주의

- 공고에 없는 업무, 역량, 문의처를 만들어내지 않습니다.
- 기업 로고는 공식 홈페이지나 공식 채용 페이지의 자산만 사용합니다.
- 카드의 쉬운 설명과 원문 출처는 `card-data.js`의 `sources`에 함께 남깁니다.
- 디자인이 깨질 때만 `styles.css`를 최소한으로 조정합니다.
