# CareerLens 카드 제작 규칙

## 목표

사용자가 제공한 실제 채용공고 URL을 조사해 이 폴더의 고정 디자인으로 공고 카드 한 장을 완성합니다. 이 결과물은 직무 이해 가설검정에 사용하므로 사실성, 쉬운 표현, 카드 간 형식 통일을 우선합니다.

## 작업 순서

1. 사용자가 제공한 채용공고 원문을 확인합니다.
2. 기업 공식 홈페이지와 공식 채용 페이지에서 회사소개, 지원 경로, 문의처, 로고를 확인합니다.
3. `CARD-GUIDE.md`를 읽고 `card-data.js`의 문구와 `sources`를 수정합니다.
4. 공식 로고 파일을 `assets/logos/`에 저장하고 `index.html`의 이미지 경로와 대체 텍스트를 바꿉니다.
5. Chrome에서 `index.html`을 실제 렌더링해 794x1123 카드 안에서 글자가 잘리지 않는지 확인합니다.
6. JavaScript 문법, 모든 데이터 바인딩, A4 인쇄 스타일을 확인합니다.
7. 최종 렌더 이미지를 `preview.png`로 저장합니다.

## 고정할 디자인

- A4 세로 794x1123 CSS px
- 초록색과 검은색의 단일 색상 체계
- 원형 제목 5칸
- 대형 제목 2줄
- 한 문장 직무 설명 띠
- 2열 정보영역 4개: 하는 일, 필요 역량, 회사소개, 용어 해설
- 하단 3박스: 접수방법, 문의처, 홈페이지
- 최하단 실제 기업 또는 대표 서비스 로고와 기업명
- 직접 편집, JSON 편집, JSON 저장, 초기화, 인쇄 기능

레이아웃, 구름형 소제목, 색상, 글꼴, 기능은 요청이 없는 한 바꾸지 않습니다. 문구가 넘칠 때는 먼저 핵심 내용을 유지한 채 문장을 다듬고, 그래도 해결되지 않을 때만 `styles.css`를 최소 조정합니다.

## 작성 원칙

- 공고 원문에 없는 내용을 추측하지 않습니다.
- 업무는 대상, 사용하는 방식, 결과물이 드러나는 구체적인 행동 문장으로 씁니다.
- 필요 역량에는 자격요건과 우대사항을 함께 반영하고, 공고에 나온 도구명과 경험을 구체적으로 적습니다.
- 우대사항은 문장 앞에 `[우대]`를 표시해 필수 능력과 구분합니다.
- 회사소개는 고객, 제품·서비스, 이용 방식, 수익 또는 협업 구조를 2-3개 문장으로 설명합니다.
- 용어 해설은 카드에 실제 등장하는 용어만 최대 3개 풉니다.
- 문의처가 없으면 `별도 안내 없음`으로 표시합니다.
- 접수 마감일과 지원 경로는 확인한 공고 기준으로 적습니다.
- 모든 요약의 근거 URL을 `card-data.js`의 `sources`에 남깁니다.
- 로고는 공식 자산을 내려받아 사용하며 임의로 새로 그리지 않습니다.

## 원형 제목

`circleTitle`은 정확히 5개 항목을 유지합니다. 단어 사이를 비워야 하면 해당 위치에 `"\u00a0"`를 사용합니다. 예시는 다음과 같습니다.

```js
circleTitle: ["A", "X", "\u00a0", "인", "턴"]
```

## 수정 범위

기본적으로 다음만 수정합니다.

- `card-data.js`
- `assets/logos/`의 로고 파일
- `index.html`의 로고 경로와 대체 텍스트
- 최종 `preview.png`

기존 예시 파일을 삭제하지 말고 새 공고에 맞게 교체한 내역을 사용자에게 알려줍니다.
