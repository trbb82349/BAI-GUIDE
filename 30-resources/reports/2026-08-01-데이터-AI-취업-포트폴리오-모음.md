## 실제 확인함 (내용 검증 완료)

### [이보민 — 데이터 분석가](https://lbm.oopy.io/) ✅
- 구성: 자기소개·연락처 → 커리어 히스토리 → 보유 스킬 → 발행 글 → 세미나/강의 → 팟캐스트 → 개인 관심사
- 내용: GA4 활용, 사용자 행동 데이터 분석(넷플릭스·아마존 사례), RFM/퍼널 분석, 마케팅 분석(UTM·이메일 지표), 커리어 조언
- 특징: 노션 기반, "직접 경험한 것 위주" 서술 철학, 프로젝트 결과물뿐 아니라 세미나·팟캐스트 등 개인 브랜딩 콘텐츠를 함께 배치. 단일 프로젝트 나열형이 아니라 **"커리어 허브" 스타일**이라 참고 가치가 높음.

### [박은상 포트폴리오](https://parkeunsang.github.io/) ✅
- 구성: Home → About → History → Portfolio (자기소개 → 경력 → 프로젝트 전시 순서)
- 내용: 머신러닝 모델링·이미지 분류·금융/스포츠 예측, Django/Vue.js 기반 영화 추천·문장 성별 분류 웹앱, 기사 저술
- 특징: 프로젝트마다 **"개요 → 세부 내용 → 기술스택 → 회고"** 포맷을 일관되게 사용. GitHub·데모 링크로 결과물 접근성을 높이고 수상 경력·팀 규모 등 맥락 정보를 함께 제시. 정적 GitHub Pages 개인 사이트라 구조를 그대로 참고하기 좋음.

### [박민지 — Data Analyst 포트폴리오 (GitHub)](https://github.com/DreamingDataScientist/PORTFOLIO) ✅
- 내용: 웹 크롤링 기반 프로젝트 2건 — 시카고 피자 맛집 분석(구글맵 API 시각화), 서울시 주유소 가격 분석(구별·브랜드별 비교)
- 특징: Jupyter Notebook 그대로 공개하는 형태. 화려한 사이트보다는 **"크롤링 → 분석 → 시각화" 파이프라인을 코드로 투명하게 보여주는** 스타일.

### [박예지 — ML/DL 프로젝트 포트폴리오 (GitHub)](https://github.com/yejipark0514/Yeji-Park) ✅
- 내용: 시계열(CO2 배출량 예측), 이미지 분류(LeNet 교통표지판, CNN 패션, CIFAR-10), 표절 탐지, 수질 변화 분석, Kaggle 대회 3건, 기상-화재 상관분석
- 특징: 프로젝트 개수가 많고(9개+) 기술 스택이 다양함(PySpark, XGBoost, HPC 환경 빅데이터 처리 등). **"양과 기술 스택 다양성으로 승부"**하는 케이스 — 신입이 여러 도메인을 얕고 넓게 다뤄봤음을 보여주는 예시로 참고할 만함.

## 공통 패턴 (벤치마킹 포인트)

1. **플랫폼은 크게 3갈래**: 노션(oopy.io 커스텀 도메인), GitHub Pages/저장소, Rallit 같은 이력서 허브 플랫폼. 진입장벽 낮은 순은 GitHub 저장소 < 노션 < 자체 사이트(박은상 케이스).
2. **프로젝트 서술 포맷이 거의 동일**: 문제 정의 → 데이터/방법 → 결과(수치) → 회고. 박은상 사이트가 이 포맷을 가장 명확하게 보여줌.
3. **프로젝트 개수는 2~3개 깊이 있게(이보민, 박민지) vs 다다익선으로 기술 스택 나열(박예지)** 두 전략이 공존. 신입일수록 후자, 실무 경험이 있으면 전자로 가는 경향.
4. **크롤링·API 연동·시각화**가 데이터 분석 포트폴리오의 단골 소재 (구글맵 API, GA4, Opinet 등 실제 외부 데이터 활용).
