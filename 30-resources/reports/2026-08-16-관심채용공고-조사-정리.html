02 직무 탐색 서비스 사전 조사를 위한 인터뷰

인터뷰 대상 — 3학년 · 행정학과

직무 탐색 상태

  • 01최근에 관심 직무를 알아보려고 했던 경험을 이야기해 주세요.최근 관심 직무를 알아보려고 채용공고와 현직자 인터뷰를 찾아봤습니다.
  • 02그때 어떤 자료나 서비스를 이용했나요?잡코리아, 사람인, 유튜브 등의 자료를 이용했습니다.
  • 03채용공고를 봤다면 실제로 무슨 일을 하는 자리인지 이해됐나요?주요 업무와 필요한 역량, 우대사항 등을 확인했습니다. 자세하게 무슨 일을 하는지는 파악하지 못한 것 같습니다.
  • 04이해하기 어려웠던 부분은 무엇이었나요?실제 업무 내용과 필요한 역량을 구체적으로 파악하는 것이 어려웠습니다.
  • 05그 자료를 본 뒤 관심 직무가 좁혀졌나요?자료를 찾아보면서 관심 직무와 필요한 역량이 조금 더 명확해졌습니다.
  • 06이해가 안 된 부분은 어떻게 해결했나요?GPT를 활용했습니다.

공고 원문 예시 질문

  • 01이 기업에서는 실제로 무슨 일을 할 것 같나요?공공기관 에너지 전문기관

공고 카드 예시 질문

  • 01이 기업에서는 실제로 무슨 일을 할 것 같나요?정부의 에너지복지 정책 대응, 에너지 취약 계층을 위한 복지 사업 기획 및 운영, 민관협력사업
  • 02관심이 생기거나 줄었다면 어떤 업무 때문인가요?정책·사업 운영 업무에 관심이 생겨서 관심도가 높아졌습니다.
  • 03카드에도 여전히 이해되지 않는 부분이 있나요? 혹은 카드에 추가로 있었으면 하는 정보가 있나요?사업 대상, 실제 업무 과정, 필요한 역량과 우대사항을 더 자세히 알면 좋겠습니다.

인터뷰 후 생각 (예상과 달랐던 반응 또는 반례)

  • 인터뷰를 하고 나니, 직무탐색을 위해 공고를 확인하는 경우는 생각보다 현실적이라는 생각이 들었다. 전공과 직무를 연결지어 필요한 나의 역량이 무엇인지 생각하기보다는, 실제 회사에서 무슨 일을 하는지, 내가 회사에 들어가서 어떤 일을 맡게 될지에 더 집중하게 되는 듯했다.
  • 또한 회사마다 향하는 목표 자체도 워낙 다양하고, 같은 직무 명칭이더라도 회사마다 업무는 조금씩 달라지기에, 공고 속 간단하고 형식적인 직무 설명에 더하여 회사 홈페이지 등의 비전 설명을 보고 예측하는 것이 직무를 이해하는 데에 가장 현실적인 방법인 것 같다는 생각을 했다.

03 내가 생각하는 최소 서비스 재현안 (직무지도 데모 기준)

채용공고를 각각 따로 보는 게 아니라, 여러 공고를 분석해서 "어떤 직무들이 실제 업무와 역량 측면에서 서로 연결되어 있는지"를 지도처럼 보여주는 서비스 기존 채용사이트가 직무를 '분류'해서 보여준다면, 이 프로그램은 실제 채용공고를 분석해 직무 간의 '관계'를 보여주려는 목표

WHY평소에는 서로 다른 직무라고 생각했던 분야가 실제 회사에서는 어떤 업무와 역량을 공유하는지 알 수 있기 때문에, 직무를 더 입체적으로 이해할 수 있습니다.

사용 전 — 못하는 것

채용사이트에서 "데이터분석", "마케팅" 같은 카테고리를 하나씩 따로 검색해야 하고, 공고 하나가 실제로는 여러 직무 역량에 걸쳐 있다는 걸 스스로 알아낼 방법이 없음.

사용 후 — 할 수 있어야 하는 판단

"내가 가진 역량(예: 데이터분석)으로 이동 가능한 인접 직무가 무엇인지", "이 직무를 준비하려면 실제 공고 기준으로 어떤 업무·역량이 필요한지"를 근거를 보고 스스로 판단할 수 있어야 함.

최소 사용자 흐름 (3~5단계)

  1. 지도에서 5개 직무 노드와 연결 강도 확인
  2. 관심 직무 클릭
  3. 인접 직무와의 유사도·공유 키워드 확인
  4. 그 직무의 실제 채용공고 카드 확인
  5. 원문 링크로 이동

핵심 결과물

지도(노드-엣지 그래프) + 클릭 시 뜨는 실제 공고 카드. 지도는 "왜 가까운가"를 보여주고 카드는 "실제로 무슨 일을 하는가"를 증명하는 역할 — 이 둘이 연결되어야 지도가 신뢰를 얻음.

범위 구분

구분내용
수작업 범위 직무기술서 PDF 양식이 표준(NCS)과 다른 경우의 텍스트 정리(15개 중 8개), 회사소개·접수정보 같은 카드 메타데이터 작성 — 기관마다 문서 양식이 제각각이라 완전 자동화가 아직 비효율적임.
구현 범위 알리오 공고 수집·제목 필터링, NCS 표준형식 PDF 자동 추출, TF-IDF 기반 카테고리 유사도 계산, SVG 지도·카드 렌더링.
제외 범위 사용자 개인 프로필 입력("내 위치" 표시), 직무 이동 경로 추천, 민간 채용사이트 등 다른 데이터 소스 통합, 역할(15개) 단위 유사도 계산(지금은 카테고리 5개 단위만).

실패 신호 — 이 방식이 틀렸다고 판단할 조건

데이터를 더 모아도 특정 카테고리(CRM 등)가 계속 비어있거나, TF-IDF 유사도가 실제 체감과 어긋나게 나오거나(예: 무관한 직무가 가깝게 뜸), PDF 형식 다양성 때문에 수작업 비중이 줄지 않고 계속 늘어나는 경우.
