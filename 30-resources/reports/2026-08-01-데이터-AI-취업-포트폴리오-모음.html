🧭 공통 패턴 (벤치마킹 포인트)

  1. 플랫폼은 크게 3갈래 — 노션(oopy.io 커스텀 도메인), GitHub Pages/저장소, Rallit 같은 이력서 허브 플랫폼. 진입장벽 낮은 순: GitHub 저장소 < 노션 < 자체 사이트(박은상 케이스).
  2. 프로젝트 서술 포맷이 거의 동일 — 문제 정의 → 데이터/방법 → 결과(수치) → 회고. 박은상 사이트가 이 포맷을 가장 명확하게 보여줌.
  3. 프로젝트 개수 전략 두 가지 — 2~3개를 깊이 있게(이보민, 박민지) vs 다다익선으로 기술 스택 나열(박예지). 신입일수록 후자, 실무 경험이 있으면 전자로 가는 경향.
  4. 크롤링·API 연동·시각화가 데이터 분석 포트폴리오의 단골 소재 (구글맵 API, GA4, Opinet 등 실제 외부 데이터 활용).
