# course-plan-timetable — 수강신청 시간표 플래너

## 한 줄 목표

강좌를 하나의 목록으로 관리하다가, 시간이 겹치면 자동으로 칸이 나뉘고 드래그로 우선순위(왼쪽=1순위)를 조정할 수 있는 HTML 시간표 도구.

## 작업 카드

- 목표: 시간표 사진처럼 요일×시간 그리드에 강좌를 표시하고, 겹치는 강좌가 있으면 칸을 나눠서 동시에 보여주되 어느 쪽을 우선할지 직접 정할 수 있게 한다.
- 입력: 사용자가 화면에서 직접 입력하는 강좌 정보(요일/시작·종료 교시/과목명/색상). 별도 파일 입력 없음.
- 출력: `src/timetable.html` 파일 하나. 브라우저로 열면 바로 사용 가능.
- 성공 기준: 겹치는 시간대의 강좌 두 개를 추가했을 때 요일 칸이 자동으로 나뉘어 나란히 보이고, 블록을 눌러 좌우로 끌면 우선순위(왼쪽=1순위) 자리가 바뀐다.
- 오늘 만든 버전: 위 기준을 모두 만족하는 완성 버전.

## 만든 기능

- [x] 강좌 추가 / 수정 / 삭제 (요일, 시작·종료 교시(A/B 반교시 포함), 과목명, **교수님 성함(선택)**, 색상)
- [x] **그리드의 강좌 블록을 클릭하면 바로 그 강좌의 수정 폼이 열림**. 이 수정 폼 안에도 "삭제" 버튼이 있어서, 목록까지 내려가지 않고 블록을 클릭한 자리에서 바로 지울 수 있습니다(강좌 목록 카드의 각 항목에도 동일하게 삭제 버튼이 있습니다).
- [x] 겹치는 시간대만 자동으로 요일 칸을 열(column)로 나누는 레이아웃 (겹치지 않으면 한 칸 그대로 사용)
- [x] **겹친 블록을 누른 채로 좌우로 끌어서 순서(우선순위) 바꾸기** — 왼쪽일수록 우선순위가 높음. 놓은 자리에 있던 강좌와 자동으로 자리를 맞바꿈. (살짝 움직이지 않고 그냥 누르면 클릭으로 인식해 수정 폼이 열림)
- [x] 그리드 시간축을 "오전 9시/오후 1시"처럼 12시간제 한글로 표시
- [x] 1교시 시작 시각 / 한 교시 길이(분) / 쉬는 시간(분) / 표시할 최대 교시를 설정에서 조절 — 학교마다 다른 교시표에 맞춤. 강좌가 범위 밖 교시를 쓰면 최대 교시가 자동으로 늘어남
- [x] **10~12교시는 "야간1~3교시"로 표시** — 기본값 기준 야간1교시 18:00~18:50, 야간2교시 19:00~19:50, 야간3교시 20:00~20:50(오후 8시 50분)까지 선택 가능
- [x] **강좌 목록의 "복제" 버튼 — 같은 강좌의 다른 시간 선택지(예: 화요일반 vs 수요일반) 추가.** 복제된 강좌들은 서로 "대안" 그룹으로 묶여서, 실제로 시간이 겹치지 않아도(다른 요일이어도) 항상 얇게 나뉘어 보이고 점선 테두리가 표시됩니다. 블록을 드래그하면 그 대안 그룹 전체의 우선순위가 요일에 상관없이 함께 바뀝니다(예: 화요일반을 왼쪽/1순위로 끌면 수요일반이 자동으로 2순위로 밀려남). 대안이 하나만 남으면 자동으로 원래 폭으로 돌아갑니다.
- [x] **화면이 좁으면(휴대폰) 시간표 그리드가 위, 강좌 추가/목록/설정 카드가 그 아래로 자동 배치**되는 반응형 레이아웃. 요일 칸도 화면 폭에 딱 맞게 줄어들어 **좌우로 슬라이드하지 않고 월~금(또는 토·일까지)이 한 화면에 한 번에** 들어옵니다.
- [x] **요일에 "이러닝(온라인/OCU 등)" 선택 가능.** 시간 입력칸이 사라지고, 시간표 맨 아래 별도 구역에 요일 칸과 상관없이 가로로 나열됩니다. 클릭하면 다른 강좌처럼 바로 수정 폼이 열립니다.
- [x] **그리드 세로 길이를 기존의 절반으로 축소**해서 전체 시간표가 훨씬 아담하게 보이고, 겹쳐서 절반 폭으로 나뉜 블록도 예전만큼 위아래로 길어 보이지 않습니다.
- [x] **강좌명이 잘리지 않고 최대 5줄까지 줄바꿈되어 표시**됩니다. 모바일처럼 칸이 아주 좁을 때(전에는 한 글자만 보이던 문제) 특히 도움이 됩니다. 블록 높이가 좁으면 그만큼만(1~4줄) 보이고, 그래도 다 안 들어가면 마지막 줄에서 잘립니다.
- [x] 토요일/일요일 표시 여부 설정
- [x] localStorage 자동 저장 (새로고침해도 유지)
- [x] JSON 내보내기 / 가져오기 (백업·복원용)
- [x] 전체 초기화 버튼

과거 있었던 "A플랜/B플랜" 같은 플랜 관리 기능은 요청에 따라 완전히 제거했습니다. 이제는 강좌 하나의 목록만 있고, 겹치는 강좌는 그리드 안에서 좌우 위치(=우선순위)로 구분합니다.

## 실행 방법

`src/timetable.html` 파일을 더블클릭하거나 브라우저 주소창에 드래그해서 엽니다. 별도 서버나 설치가 필요 없습니다.

## 확인 방법

1. 시간이 겹치는 강좌 두 개(예: 월요일 4~6교시, 월요일 5~6교시)를 추가합니다. 하나에는 교수님 성함도 넣어보세요.
2. 시간표에서 월요일 칸이 좌우로 나뉘어 두 강좌가 동시에 보이는지, 교수님 성함을 넣은 블록에 그 이름이 작게 표시되는지 확인합니다.
3. 아무 블록이나 살짝 클릭(움직이지 않고 눌렀다 떼기)하면 왼쪽에 그 강좌의 수정 폼이 바로 뜨는지 확인합니다.
4. 겹친 블록 중 왼쪽 블록을 마우스로 누른 채 오른쪽 블록 자리까지 끌고 놓습니다.
5. 두 블록의 좌우 위치가 바뀌면 성공입니다(원래 오른쪽에 있던 강좌가 왼쪽=1순위로 이동). 이때는 수정 폼이 열리지 않아야 합니다. 새로고침해도 바뀐 순서가 유지되는지도 확인하세요.
6. 그리드 왼쪽 시간축이 "오전 9시", "오후 1시"처럼 12시간제로 보이는지도 확인하세요.
7. 강좌 하나를 추가한 뒤 "복제" 버튼을 누르고, 열리는 수정 폼에서 요일만 다른 요일로 바꿔 저장합니다. 두 요일 모두 시간이 겹치지 않는데도 블록이 절반 너비로, 점선 테두리와 함께 보이면 성공입니다.
8. 둘 중 한 블록을 눌러서 반대쪽으로 끌어 봅니다. 다른 요일에 있는 블록의 좌우 위치가 함께 바뀌면(=우선순위가 요일을 넘어 연동되면) 성공입니다.
9. 브라우저 창을 휴대폰 너비 정도로 좁히거나 실제 휴대폰으로 열어봅니다. 시간표 그리드가 위쪽에, 강좌 추가/목록/설정 카드가 그 아래로 세로로 쌓여서 보이면 성공입니다. 월~금(토·일까지 켜도) 요일이 옆으로 밀지 않고 화면 안에 한 번에 다 들어오는지 확인하세요.
10. 요일에서 "이러닝"을 선택합니다. 시작·종료 교시 입력칸이 사라지고 안내 문구가 뜨면 성공입니다. 과목명만 넣고 추가하면, 시간표 그리드 맨 아래 "이러닝" 구역에 가로로 블록이 생기고(요일 칸 안에는 안 나타남) 강좌 목록에도 시간 없이 "이러닝"으로만 표시되면 성공입니다.
11. 전체 시간표 높이가 예전보다 눈에 띄게 낮아졌는지(대략 절반) 확인하세요. 이름이 긴 강좌(예: "AI시대의 글쓰기와 글쓰기 이론과 실체")를 추가해서, 블록 안에서 잘리지 않고 여러 줄로 줄바꿈되어 보이는지도 확인하세요 — 특히 휴대폰 너비에서 칸이 좁을 때 효과가 큽니다.
12. 시간표의 강좌 블록을 하나 클릭합니다. 왼쪽 수정 폼에 "수정 완료" 옆으로 빨간 "삭제" 버튼이 뜨는지, 눌러서 확인 후 그 강좌가 시간표와 목록에서 바로 사라지는지 확인하세요.

## 다음에 요청할 말

- "우리 학교 교시표는 이렇대, 기본값 맞춰줘" — 학교의 정확한 교시-시각 대응표를 알려주면 기본 설정값을 바꿔드릴 수 있습니다.
- "겹친 블록에 순위 숫자(1순위/2순위)도 같이 보여줘" — 드래그 없이도 우선순위를 한눈에 보고 싶을 때
- "시간표를 이미지(PNG)로 내보내는 기능 추가해줘" — 캡처 없이 바로 저장하고 싶을 때
- "실제 폰으로 테스트해보니 이 부분이 불편해" — 반응형 레이아웃은 만들었지만 실제 터치 기기에서 직접 확인해보진 못했으니, 써보고 어색한 부분이 있으면 알려주세요.

## 메모

- 데이터는 이 브라우저의 localStorage에만 저장됩니다. 다른 컴퓨터/브라우저로 옮기려면 "내보내기(JSON)"로 백업한 뒤 그쪽에서 "가져오기"로 불러오세요.
- 겹침 판정은 "시간이 겹치는 강좌끼리 묶기(클러스터링)" 알고리즘을 그대로 쓰되, 클러스터 안에서 열 순서는 더 이상 자동 배정이 아니라 각 강좌의 `order`값(=우선순위)을 기준으로 정합니다. 드래그로 블록을 옮기면 그 자리에 있던 강좌와 `order`값을 맞바꿔서 순서를 반영합니다.
- 이전 버전에 있던 "플랜(A/B/C) 관리" 데이터가 브라우저에 남아있어도, 열 때 자동으로 하나의 강좌 목록으로 합쳐집니다(마이그레이션 처리). 기존에 추가해두신 강좌는 그대로 유지됩니다.
- **교시 A/B 규칙(추정치)**: 한 교시를 앞 절반(A)·뒤 절반(B)으로 나눠, "2B~3교시"처럼 정각에 안 걸리는 수업 시작·끝점을 표현한다고 가정했습니다. 기본값은 1교시 = 오전 9:00 시작, 한 교시 = 60분(절반 30분), 쉬는 시간 = 10분입니다. 학교의 실제 교시표와 다르면 왼쪽 "시간표 설정"에서 값을 조절하면 모든 강좌 시간이 자동으로 다시 계산됩니다. 정확한 교시표(수강신청편람 등)를 확인하면 알려주세요 — 기본값을 학교에 맞게 고쳐드릴 수 있습니다.
- 강의실 정보는 더 이상 입력받지 않습니다(요청에 따라 제거). 대신 교수님 성함(선택)을 입력할 수 있습니다.
- 블록을 누른 채 6px 넘게 움직이면 "드래그"로, 그보다 적게 움직이면(또는 그대로 떼면) "클릭"으로 인식해 수정 폼을 엽니다.
- 야간 교시 표시 기준은 1~9교시=주간, 10교시부터=야간1·2·3···으로 코드에 고정돼 있습니다(주간 교시 개수를 다르게 바꾸고 싶으면 알려주세요). 표시할 최대 교시 기본값을 12로 올려서 야간3교시(오후 8시 50분 종료)까지 기본으로 선택할 수 있고, 예전에 최대 교시를 10으로 저장해둔 브라우저도 열 때 자동으로 12까지 올라갑니다.
- "대안" 그룹은 내부적으로 `groupId`로 연결됩니다. 시간이 겹치는 클러스터의 열 배정 로직을 그대로 재사용하되, 같은 그룹의 다른 요일 강좌를 "실제로는 안 보이지만 자리는 차지하는" 가상 구성원으로 끼워 넣어 폭과 우선순위를 계산합니다. 강좌를 지워서 그룹 구성원이 1명만 남으면 그룹이 자동으로 해제됩니다.
- 화면 너비 840px 이하에서 반응형 레이아웃(그리드 위, 카드 아래)이 적용됩니다. 이 기준을 바꾸고 싶으면(예: 태블릿에서도 좌우 배치를 유지하고 싶다면) 알려주세요.
- 좁은 화면에서는 요일 칸에 강제 최소 너비를 두지 않고(`minmax(0,1fr)`) 화면 폭을 요일 수만큼 정확히 나눠 쓰기 때문에 슬라이드 없이 다 들어옵니다. 칸이 아주 좁아져도 강좌명은 (아래 항목처럼) 여러 줄로 줄바꿈되어 최대한 보여집니다.
- 이러닝 강좌는 내부적으로 요일 값이 `"online"`으로 저장되고 시작·종료 교시 필드가 아예 없습니다. 겹침 판정·열 나누기·시간축 계산(요일별 시간 그리드) 로직에서는 전부 제외되고, 그리드 아래 별도의 가로 목록으로만 그려집니다. "복제" 버튼으로 이러닝 강좌를 여러 개 만들 수도 있지만, 시간이 없는 만큼 우선순위 드래그·자동 칸 나누기 같은 "대안" 시각 효과는 적용되지 않습니다(강좌 목록의 "대안 N개 중 하나 선택" 문구만 표시).
- 그리드의 분당 픽셀 값(`pxPerMin`)을 1.5 → 0.75로 낮춰서 세로 길이를 정확히 절반으로 줄였습니다. 더/덜 축소하고 싶으면 이 값을 조절하면 됩니다. 강좌명은 `-webkit-line-clamp`로 최대 5줄까지 줄바꿈 후 자르는데, 블록이 5줄보다 낮으면 실제로는 그보다 적은 줄만 보이고 나머지는 블록 테두리에서 잘립니다(자연스러운 동작이며 오류 아님).
