# Automation Next Steps

## 1. RSS 대상 바꾸기

현재 입력 파일은 `input/korean-news-feeds.csv`입니다.
원하는 언론사나 주제 RSS가 있으면 이 파일의 `url` 값을 바꾸면 됩니다.

## 2. 요약 품질 높이기

현재 스크립트는 RSS의 제목과 설명을 정리해서 짧은 요약을 만듭니다.
더 자연스러운 요약이 필요하면 다음 단계에서 요약 모델이나 API를 붙일 수 있습니다.

요약 규칙 예시:

- 제목과 출처는 유지한다.
- 각 뉴스는 2문장 이하로 줄인다.
- 학생이 이해하기 어려운 표현은 쉬운 한국어로 바꾼다.
- 정치, 경제, AI처럼 분야별로 묶어 보여준다.

## 3. 이메일 발송 붙이기

메일 발송에는 계정 설정이나 앱 비밀번호가 필요합니다.
실제 비밀번호를 코드에 넣지 않고, `config.example.json` 같은 예시 파일만 만든 뒤 사용자 PC에서 직접 값을 넣는 방식이 안전합니다.

## 4. 매일 실행 예약하기

Windows에서는 작업 스케줄러를 사용합니다.

기본 흐름:

1. Python 스크립트가 수동으로 잘 실행되는지 확인한다.
2. 작업 스케줄러에서 새 작업을 만든다.
3. 트리거를 매일 오전 8시로 설정한다.
4. 동작에 Python 실행 파일과 `src/main.py` 경로를 넣는다.
5. 실행 후 `output/korean-news-report.md`가 갱신되는지 확인한다.
