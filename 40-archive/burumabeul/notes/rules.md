# 참고한 부루마블 규칙 요약

나무위키 `부루마불/게임 방법` 문서는 봇 차단으로 직접 열람하지 못해, 검색 결과 요약과 다른 정리 글(윙보드게임 블로그 등)에서 확인한 핵심 규칙을 참고해 구현했습니다. 보드 배치(도시 이름·순서·구역)는 사용자가 실제 보드 사진을 보고 직접 알려준 내용을 그대로 반영했습니다.

## 보드 배치 (40칸, 사용자 지정)

출발(코너) → 빨간 구역(타이페이~이스탄불, 9칸, 싱가포르와 카이로 사이에 황금열쇠 추가) → 무인도(코너) → 초록 구역(아테네~몬트리올, 9칸, 콩코드여객기 포함) → 사회복지기금 수령처(코너) → 갈색 구역(부에노스아이레스~마드리드, 9칸, 퀸엘리자베스호 포함) → 우주여행(코너) → 검은 구역(도쿄~서울, 9칸, 콜롬비아호 포함) → 출발로 순환.

네 구역 모두 9칸씩이라 11x11 격자 테두리(4×10=40칸)에 정확히 맞아떨어져, 이전 버전에 있던 장식용 빈칸이 없어졌습니다.

## 참고한 핵심 규칙

- 주사위 2개를 굴려 나온 합만큼 이동. 같은 숫자(더블)가 나오면 폭죽 이모지와 함께 "더블!" 팝업이 잠깐 떴다 사라진 뒤 한 번 더 굴린다. 3연속 더블은 무인도로 이동.
- 말이 한 칸씩 이동하는 도중 화면 아무 곳이나 클릭하면 남은 이동을 건너뛰고 바로 목적지에 도착한다.
- 출발점을 지나면 은행에서 월급을 받는다. 정확히 출발점에 도착하면 보너스를 더 받는다.
- 빈 땅에 도착하면 구매할 수 있다. 이미 다른 사람 소유면 얼마를 내야 하는지 보여주는 확인 창이 뜨고, "확인"을 눌러야 통행료가 실제로 지불된다.
- 별장/빌딩/호텔은 서로 독립된 건물이다. 어떤 조합으로든 각각 따로 사고팔 수 있고, 통행료는 대지세(10%) + 소유한 건물마다의 추가 통행료(건설비의 1.5배)를 전부 더한 값이다.
- 제주도·부산·서울·콩코드여객기·퀸엘리자베스호·콜롬비아호는 건물을 지을 수 없는 특수 칸으로, 가격과 통행료가 고정값이다.
- 콩코드여객기·퀸엘리자베스호·콜롬비아호는 도시가 아닌 "탈것" 칸으로, 건물은 못 짓지만 같은 사람이 여러 개 가질수록 통행료가 올라간다.
- 무인도(감옥)에 도착하면 "갇혔습니다" 창이 뜨고 "확인"을 눌러야 한다. 3회 동안 갇히고, 주사위 더블이 나와야 탈출한다. 탈출 시도마다 성공/실패를 알려주는 창이 뜨고 "확인"을 눌러야 다음으로 넘어간다. 실패하면 벌금을 내고 강제 석방.
- 사회복지기금 납부처(일반 칸): 도착하면 금액을 보여주는 창이 뜨고 "확인"을 눌러야 무조건 기금을 낸다. 사회복지기금 수령처(코너): 도착하면 금액을 보여주는 창이 뜨고 "확인"을 눌러야 쌓인 기금 전액을 받는다.
- 황금열쇠 칸: 카드 내용이 창으로 뜨고, "확인"을 눌러야 지시(상금, 세금, 우대권, 무인도 탈출카드, 반액매출 등)가 실제로 적용된다. "반액 대매출"은 땅값만이 아니라 지은 건물 값까지 합친 총액이 가장 큰 자산을 골라 그 총액의 절반을 받고 매각한다.
- 우대권: 통행료 1회 면제. 상대 땅에 걸렸을 때 우대권이 있으면 자동으로 쓰이지 않고, "우대권 사용하기 / 그냥 지불하기" 중 고르는 선택 창이 뜬다.
- 우주여행 칸: 이용료를 낸다는 확인 창이 뜨고 "확인"을 눌러야 실제로 지불된다(콜롬비아호 주인이 있으면 그 사람에게, 없으면 은행에). 그 턴에는 더 이동하지 않고, 다음 턴에 주사위를 굴리는 대신 보드에서 원하는 칸을 하나 골라 바로 그곳으로 이동한다.

## 이번 구현에서 단순화한 부분

- 색상 구역을 다 모아야 건물을 지을 수 있는 규칙은 없음 (땅 하나만 있어도 건물 가능)
- 경매, 우선매수권, 대출(차용) 규칙 없음
- 실제 시판 버전의 정확한 가격·통행료 수치와는 다름 (자체적으로 40,000원~290,000원 단계로 구성, 최초 80,000원~580,000원에서 절반으로 인하)

## 이번 구현에서 정한 수치 (참고용, `src/부루마블.html` 안 상수와 동일)

- 시작 자금: 8,000,000원
- 출발점 통과 월급: 300,000원 (정확히 도착하면 추가 300,000원 보너스)
- 도시 가격: 40,000원 ~ 290,000원 (경로를 따라 점점 비싸짐, 최초 가격의 절반). 단, 제주도(200,000원)·부산(500,000원)·서울(1,000,000원)은 사용자가 지정한 고정값.
- 탈것 가격: 콩코드여객기 200,000원 / 퀸엘리자베스호 250,000원 / 콜롬비아호 450,000원 (사용자 지정 고정값)
- 건물 짓기 비용(각각 독립, 순서 상관없음): 별장 = 땅값 50%, 빌딩 = 땅값 180%(기존의 3배), 호텔 = 땅값 320%(기존의 4배)
- 통행료: 대지 10%(항상) + 별장 소유 시 75% + 빌딩 소유 시 270% + 호텔 소유 시 480% (모두 소유하면 최대 835%, 땅값 기준). 건물 통행료는 항상 그 건물 건설비의 1.5배가 되도록 맞췄습니다.
- 제주도·부산·서울·콩코드여객기·퀸엘리자베스호·콜롬비아호는 통행료가 고정값(각각 250,000 / 600,000 / 2,000,000 / 300,000 / 400,000 / 400,000원)이고, 건물을 지을 수 없습니다.
- 우주여행 코너에 걸리면 위 이용료와 별개로, 콜롬비아호 소유자가 있으면 그 사람에게 200,000원을 추가로 지불합니다.
- 매각 환급액: 건물이든 땅(제주도·부산·서울 등 특수 칸, 탈것 포함)이든 지었던/샀던 비용 그대로 100% 환급. (건물이 하나라도 남아있으면 땅 자체는 팔 수 없고 건물부터 매각). 단, 황금열쇠 "반액 대매출" 카드는 (땅값+건물값 합계)의 절반만 받고 강제 매각.
- 무인도 탈출 실패 3회 시 벌금 150,000원 내고 강제 석방
- 사회복지기금 납부액: 200,000원
- 증서(구매 화면·보유 자산 카드)에는 현재 상태 기준으로 상대가 걸렸을 때 낼 통행료가 항상 같이 표시됩니다.
- 말은 목적지까지 한 칸씩 실제로 이동하며(칸마다 효과음), 순간이동하지 않음. 이동 간격은 사람·NPC 동일하게 0.48초입니다.
- 가운데 패널 테두리 색으로 지금 누구 턴인지 표시: 파란 테두리=플레이어, 빨간 테두리=NPC
- NPC가 땅을 사거나(구매 화면) 건물을 지을 때(관리 화면), 남의 땅에 걸려 통행료를 낼 때, 우대권 사용 여부를 정할 때, 황금열쇠 카드를 뽑을 때, 무인도에 갇히거나 탈출을 시도할 때, 사회복지기금을 내거나 받을 때, 우주여행 요금을 낼 때 모두 사람이 보는 것과 같은 카드 창이 반투명하게("🤖 NPC 진행 중...") 자동으로 떴다 닫힙니다. 클릭은 막혀 있고, 일정 시간 후 자동으로 결정되어 넘어갑니다. NPC는 우대권 선택 창에서 항상 "사용하기"를 자동 선택합니다.
- 보드 격자는 11x11이지만 칸 크기가 균일하지 않습니다. 코너 4칸과 좌/우 테두리 칸의 폭, 위/아래 테두리 칸의 높이는 105px로 크게, 그 외 안쪽 방향 치수는 62px로 좁게 잡아서 위/아래 줄 칸은 세로로 긴 직사각형, 좌/우 줄 칸은 가로로 긴 직사각형이 되도록 했습니다. 코너는 105x105 정사각형이라 가장 큽니다. 이 덕분에 가운데 흰 패널(주사위/로그 영역)은 9x9칸 * 62px 기준으로 계산되어 이전보다 작아졌고, 칸 하나의 넓이(62*105=6510)는 이전 정사각형 칸(76*76=5776)보다 커졌습니다.
- 주사위 눈(점) 색이 지금 차례에 맞춰 바뀝니다: 플레이어 턴이면 파란색, NPC 턴이면 빨간색.
- NPC 전용 대기 시간을 전반적으로 약 2배로 늘렸습니다: 주사위 굴리기 전 "굴리는 중" 표시(0.4→0.8초), 주사위 결과를 보여주는 시간(0.9→1.8초), 카드 확인 시간(약 1.2초, 사람의 클릭 대기에 해당). 한 칸 이동 간격은 사람도 같은 속도(0.48초)로 맞췄습니다.
- 우주여행 목적지 선택: 사람은 보드에서 원하는 칸을 직접 클릭해서 고르고(선택 가능한 칸은 주황색으로 반짝임), NPC는 살 수 있는 빈 땅이 있으면 그중 하나를, 없으면 무작위 칸을 자동으로 고릅니다.
- 국기 이모지가 일부 환경에서 이미지로 렌더링되지 않는 문제 때문에, 도시 26칸(23개국)의 국기를 전부 CSS(색 그라디언트 조합)로 직접 그려 넣었습니다. 브라우저·폰트와 무관하게 항상 이미지로 보입니다.
- 제주도·부산·서울·무인도·콩코드여객기·퀸엘리자베스호·우주여행·콜롬비아호 8칸은 작은 아이콘 대신 칸 전체 배경을 테마 그라디언트(하늘/바다/노을 색)와 큰 이모지(🍊🌉🗼🏝️✈️🚢🛸🚀)로 채운 "배경 이미지" 스타일을 적용했습니다.
