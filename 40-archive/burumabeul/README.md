# 부루마블 (플레이어 vs NPC)

## 한 줄 목표

나무위키 부루마블 게임 방법을 참고해, 사람 한 명 + 자동 진행 NPC 한 명이 브라우저에서 바로 즐기는 2인용 부루마블 웹 게임 만들기.

## 작업 카드

- 목표: 더블 이동, 땅 구매, 통행료, 건물(별장/빌딩/호텔), 무인도, 황금열쇠, 사회복지기금, 우주여행, 파산까지 갖춘 미니 부루마블을 HTML 한 파일로 구현
- 입력: 없음 (규칙은 `src/부루마블.html` 안 상수, 정리본은 `notes/rules.md`)
- 출력: `src/부루마블.html` (더블클릭해서 여는 완성된 게임)
- 성공 기준: 브라우저에서 열었을 때 "게임 시작"을 누르면 사람이 주사위를 굴리고 NPC가 자동으로 턴을 진행하며, 둘 중 한쪽이 파산하거나 "게임 종료" 버튼을 누르면 승자가 표시됨
- 오늘 만든 최소 버전: 완성 (아래 "만들 기능" 전부 구현)

## 만들 기능

- [x] 40칸 순환 보드, 실제 보드 사진 기준 배치 (빨강/초록/갈색/검정 4개 구역, 각 9칸씩 + 코너 4개 — 싱가포르와 카이로 사이에 황금열쇠 추가)
- [x] 도시 26개 + 탈것 3개(콩코드여객기/퀸엘리자베스호/콜롬비아호, 소유하면 통행료를 받는 특수 칸) + 황금열쇠 6개
- [x] 제주도·부산·서울·콩코드여객기·퀸엘리자베스호·콜롬비아호는 가격·통행료가 고정값이고 건물을 지을 수 없는 특수 칸
- [x] 주사위 2개, 더블이면 한 번 더 (3연속 더블은 무인도行) — 실제로 회전하는 3D 주사위 애니메이션
- [x] 빈 땅 구매 / 남의 땅 통행료 (건물 단계별로 통행료 차등, 탈것은 보유 개수에 비례)
- [x] 별장·빌딩·호텔은 서로 독립된 건물이라 순서 상관없이 원하는 것만 골라 지을 수 있고, 지은 것만 각자 매각 가능 (호텔만 지어도 별장/빌딩은 계속 따로 구매 가능)
- [x] 무인도: 갇힐 때, 그리고 탈출 시도 성공/실패할 때마다 창이 뜨고 "확인"을 눌러야 다음으로 넘어감. 3회 안에 더블 나오면 탈출, 실패하면 벌금 내고 석방
- [x] 황금열쇠 카드 14종 (상금/세금/우대권/무인도 탈출카드/반액매출 등) — 카드가 창으로 뜨고 "확인"을 눌러야 실제로 적용됨. "반액 대매출"은 땅값만이 아니라 건물까지 합친 총 가치가 가장 비싼 자산을 골라 그 총액의 반값에 매각
- [x] 사회복지기금 납부처(기부) / 수령처(코너, 전액 수령) 분리 — 둘 다 "얼마를 낸다/받는다" 창이 뜨고 "확인"을 눌러야 실제로 처리됨
- [x] 우주여행: 이용료를 낸(콜롬비아호 주인이 있으면 그 사람에게) 턴에는 그대로 멈춰있고, 다음 턴에 주사위 대신 보드에서 원하는 칸을 직접 클릭해서 바로 이동
- [x] 파산 처리 및 게임 종료, "재산 비교로 수동 종료" 버튼
- [x] NPC 자동 진행 (구매/건설 판단 로직 포함)
- [x] 파란/빨간 종이비행기 모양 말, 제목과 똑같은 손글씨 폰트(Jua) 하나로 전체 통일, 파스텔 보드 디자인, 더 커진 칸 이름·땅값 글씨
- [x] 주사위 굴리는 소리, 말이 한 칸씩 실제로 지나가며 통통 튀는 이동 효과음 (Web Audio API로 직접 합성, 외부 음원 파일 없음)
- [x] 시작 자금 각 8,000,000원, 땅값은 전체 절반으로 인하 (40,000원~290,000원)
- [x] 돈이 오갈 때(구매/건설/통행료/매각/월급 등) 짤랑거리는 코인 효과음
- [x] 건물을 색깔 막대로 표시: 별장(빨강, 낮음)·빌딩(노랑, 중간)·호텔(파랑, 높음) 중 실제로 지은 것만 정확히 보임 (호텔만 지으면 파란 막대 하나만)
- [x] 부동산 "증서" 카드 시스템: 땅에 도착하면 지역 색과 국기로 꾸며진 증서가 펼쳐지며 구매 여부를 고르고, 구매 후 그 자리에서 별장/빌딩/호텔을 각각 독립적으로 짓거나 매각 가능
- [x] 사이드바에 보유한 증서가 칩으로 표시되고, 내 턴이면 언제든 클릭해서 건물을 더 짓거나 건물·땅을 매각 가능
- [x] 모든 칸과 증서에 국기를 눈에 띄게 배치 (칸은 이름 위 전용 자리, 증서는 카드 맨 위 큰 국기)
- [x] 증서에 상대가 걸렸을 때 낼 통행료를 항상 같이 표시 (건물 상태에 따라 실시간으로 갱신)
- [x] 말 이동 속도를 플레이어·NPC 모두 동일하게 칸당 0.48초로 통일 (전보다 느려짐)
- [x] 가운데 패널 테두리로 지금 누구 턴인지 표시: 파란 테두리=플레이어, 빨간 테두리=NPC
- [x] 배경을 채도 낮은 연한 초록색으로 바꾸고, 지구본·구름·나무 등 이모지 일러스트로 은은하게 장식
- [x] 상대 소유지에 걸리면 "누가 누구에게 얼마"를 보여주는 통행료 확인 창이 뜨고, "확인" 버튼을 눌러야 실제로 지불됨
- [x] 우대권을 갖고 있을 때 상대 땅에 걸리면 자동으로 쓰이지 않고, "우대권 사용하기 / 그냥 지불하기" 중 고르는 선택 창이 뜸
- [x] 우주여행 칸에 걸리면 이용료를 낸다는 확인 창이 뜨고 "확인"을 눌러야 실제로 지불됨
- [x] 건물뿐 아니라 땅(제주도·부산·서울 등 특수 칸, 콩코드여객기·퀸엘리자베스호·콜롬비아호 포함) 매각도 구매했던 가격 그대로 100% 환급
- [x] NPC가 땅을 사거나 건물을 짓거나 황금열쇠를 뽑을 때도 사람과 똑같은 카드 창이 반투명하게("🤖 NPC 진행 중..." 표시) 떠서 무엇을 하는지 보임 — 클릭은 못 하고 자동으로 결정되어 넘어감
- [x] NPC의 전체 진행 속도를 약 2배 느리게 조정 (주사위 굴리는 대기 시간, 이동 칸 간격, 카드 확인 시간 모두 포함)
- [x] 빌딩 건설비 3배, 호텔 건설비 4배로 인상 (별장은 그대로). 통행료도 새 건설비의 1.5배로 재계산
- [x] 주사위 눈 색이 지금 턴에 맞춰 바뀜: 플레이어 턴이면 파란색, NPC 턴이면 빨간색
- [x] 보드 레이아웃 개편: 가운데 흰 패널을 더 작게 줄이고, 그만큼 각 칸을 길쭉한 직사각형으로 키움 (칸 하나의 넓이는 오히려 더 커짐). 코너 칸은 정사각형으로 더 커짐
- [x] 말이 한 칸씩 이동하는 애니메이션 중에 화면 아무 곳이나 클릭하면 나머지 이동을 건너뛰고 바로 도착
- [x] 더블(같은 눈)이 나오면 바로 폭죽 이모지와 함께 "더블!" 알림 팝업이 잠깐 떴다 사라짐
- [x] 제주도·부산·서울·무인도·콩코드여객기·퀸엘리자베스호·우주여행·콜롬비아호 8칸은 작은 아이콘이 아니라 칸 배경 전체가 테마 이미지(그라디언트 배경 + 큰 이모지)로 채워짐

## 실행 방법

`10-projects/burumabeul/src/부루마블.html` 파일을 더블클릭하거나 브라우저로 열면 바로 실행됩니다. (별도 서버, 설치 필요 없음)

## 확인 방법

1. "게임 시작" 버튼을 눌러본다.
2. 파란 토큰(P, 나)일 때 "주사위 굴리기"를 눌러 진행하고, 빈 땅에서 증서 카드가 펼쳐지며 "구매하기/구매하지 않기"와 통행료 미리보기가 뜨는지 확인한다. 구매하면 그 자리에서 건물 등급(별장/빌딩/호텔)을 바로 선택할 수 있는지 확인한다.
3. 내가 NPC 소유의 땅에 걸리면 "얼마를 누구에게 지불" 창이 뜨고 "확인"을 눌러야 실제로 돈이 나가는지 확인한다. 우대권이 있는 상태에서 걸리면 자동으로 안 쓰이고 "우대권 사용하기/그냥 지불하기" 선택 창이 뜨는지 확인한다. 황금열쇠 칸에 걸리면 카드 내용이 창으로 뜨고 "확인"을 눌러야 적용되는지도 확인한다. 무인도에 걸리면 "갇혔습니다" 창이, 탈출 시도 후에는 성공/실패 창이 뜨고 각각 "확인"을 눌러야 넘어가는지 확인한다. 사회복지기금 납부처/수령처에 걸려도 금액을 보여주는 창이 뜨고 "확인"을 눌러야 처리되는지 확인한다.
4. 우주여행 칸에 걸리면 이용료를 낸다는 확인 창이 뜨고 "확인"을 눌러야 실제로 지불되는지, 그 턴은 그대로 끝나는지, 다음 내 턴에 "주사위 굴리기" 대신 보드 칸들이 주황색으로 반짝이며 클릭해서 고를 수 있는지, 고른 칸으로 바로 이동해 정상적으로 땅 구매/통행료 등이 처리되는지 확인한다.
5. 빨간 토큰(N, NPC)일 때는 반투명한 카드 창이 자동으로 떴다 닫히며 진행되는지 확인한다 (NPC가 땅을 사거나 건물을 짓거나 황금열쇠를 뽑거나 통행료를 내거나 우대권 여부를 정하거나 우주여행 요금을 내거나 무인도에 갇히거나 탈출을 시도할 때 모두). 이전보다 확실히 느려져서 따라가기 편한지도 확인한다. 내 턴/NPC 턴이 바뀔 때 가운데 패널 테두리와 주사위 눈 색이 파란색/빨간색으로 바뀌는지도 확인한다.
6. 사이드바에서 두 플레이어의 자금과 보유 증서 칩이 실시간으로 바뀌는지 확인한다. 내 턴일 때 증서 칩을 클릭하면 건물 추가/매각 카드가 통행료와 함께 다시 열리는지, 건물 매각 환급액이 지은 비용과 같은지 확인한다.
7. 아무 쪽이나 파산하거나 "게임 종료(재산 비교)"를 누르면 상단 상태 표시줄에 승자가 뜨는지 확인한다.
8. 보드를 봤을 때 위/아래 줄 칸은 세로로 길쭉하고, 좌/우 줄 칸은 가로로 길쭉한 모양인지, 코너 칸은 큰 정사각형인지, 가운데 흰 패널이 예전보다 작아졌는지, 각 도시/탈것 칸에 국기(또는 탈것 아이콘)가 잘 보이는지 확인한다.
9. 말이 한 칸씩 움직이는 도중에 화면 아무 곳이나 클릭해서 바로 목적지에 도착하는지 확인한다. 더블이 나오면 폭죽 이모지와 "더블!" 팝업이 잠깐 떴다 사라지는지 확인한다.
10. 제주도·부산·서울·무인도·콩코드여객기·퀸엘리자베스호·우주여행·콜롬비아호 칸이 작은 아이콘이 아니라 칸 전체가 색 배경 + 큰 이모지로 채워져 있는지 확인한다.

게임 엔진 로직(파산 처리, 무한 루프 여부)은 Node.js로 양쪽을 NPC로 돌려 자동 시뮬레이션했고, 증서 구매/건설/매각 흐름도 별도 스크립트로 금액 계산까지 검증했습니다.

## 메모

- 나무위키 원문(`부루마불/게임 방법`)은 봇 차단으로 직접 열람하지 못해, 검색 요약과 다른 정리 글을 참고해 재구성했습니다. 보드의 도시 이름·순서·구역 색은 사용자가 실제 보드 사진을 보고 알려준 내용을 그대로 반영했고, 가격·통행료 수치는 자체적으로 정한 것입니다. 자세한 내용은 `notes/rules.md` 참고.
- 색상 그룹 매수, 경매, 우선매수권, 대출 규칙은 이번 버전에 없습니다.
- 구글 폰트(Jua)를 온라인에서 불러오므로, 인터넷 연결이 없으면 기본 글꼴로 대체되어 보입니다(게임 진행에는 문제없음).
- 효과음은 브라우저 자동재생 정책 때문에 "게임 시작" 버튼을 눌러야 소리가 켜집니다.

- 땅(대지) 매각도 이제 건물과 마찬가지로 구매가 그대로 100% 환급됩니다. 파산으로 강제 매각될 때도 동일하게 100% 환급이 적용됩니다.
