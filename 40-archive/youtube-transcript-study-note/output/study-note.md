## 한 줄 요약

클로드 코드는 코딩 도구라기보다, 반복 업무를 맡길 AI 신입사원을 채용하고 교육하고 검증해서 자동화 시스템으로 만드는 작업 방식이다.

## 핵심 메시지

- 코딩 실력보다 중요한 것은 AI에게 맡길 일을 명확하게 정의하는 능력이다.
- 처음부터 큰 자동화를 만들기보다, 매일 반복하는 작고 단순한 업무 하나를 골라 시작한다.
- `CLAUDE.md` 같은 프로젝트 지침 파일은 회사 매뉴얼처럼 작동하며, AI가 작업을 판단하는 기준이 된다.
- 플랜 모드로 먼저 계획을 검토하고 승인한 뒤 실행하면 초보자도 더 안전하게 작업할 수 있다.
- API 키와 비밀값은 코드에 직접 넣지 않고 `.env` 같은 별도 파일로 관리해야 한다.
- 결과물이 나오면 보안 리뷰와 품질 피드백을 반복해 자동화 시스템을 점점 개선한다.

## 영상 흐름

### 1. 클로드 코드를 AI 신입사원처럼 보기

영상은 클로드 코드를 단순한 코딩 도구가 아니라 “AI 신입사원”으로 비유한다. 사용자는 업무를 정리하고, 작업 공간을 만들고, 매뉴얼을 주고, 결과를 검토하는 사장 또는 팀장 역할을 맡는다.

### 2. VS Code와 클로드 코드 세팅

클로드 코드는 VS Code 안에서 사용한다. VS Code를 설치한 뒤 확장 프로그램에서 클로드 코드를 설치하고 로그인한다. 무료 버전만으로는 사용이 어렵고, 최소 프로 이상 요금제가 필요할 수 있다는 점도 설명한다.

### 3. 작업 모드 이해

- `Ask before editing`: 파일을 바꾸기 전에 매번 확인받는 모드
- `Edit automatically`: 사용자의 추가 확인 없이 수정하는 모드
- `Plan mode`: 실제 파일을 바꾸기 전에 실행 계획을 먼저 보고하는 모드
- `Bypass permissions`: 검증된 뒤 더 많은 권한을 위임하는 모드

초보자는 먼저 플랜 모드나 확인 모드로 시작하는 것이 좋다.

### 4. 자동화할 업무 정의

영상의 예시는 “매주 유튜브 트렌드를 분석하고 PDF 리포트를 이메일로 받는 자동화”다. 여기서 중요한 것은 도ㅍ고르는 것이 아니라, 입력, 처리, 판단, 출력의 틀을 먼저 정하는 것이다.

### 5. `CLAUDE.md`로 업무 매뉴얼 만들기

`CLAUDE.md`는 프로젝트의 설계도이자 규칙 파일이다. 워크플로우, 에이전트, 툴 구조를 정리해 두면 클로드 코드가 그 기준에 따라 파일을 만들고, 오류를 고치고, 문서도 업데이트한다.

### 6. API, MCP, 스킬의 역할

- API: 유튜브, Gmail, Notion 같은 서비스를 코드로 직접 호출하는 방식
- MCP: 외부 서비스를 AI가 더 쉽게 다룰 수 있게 해 주는 연결 통로
- 스킬: PDF 생성, 시각화처럼 특정 작업을 더 잘하게 만드는 전문 지침

상황에 따라 API가 더 안정적일 수도 있고, MCP가 더 편할 수도 있다.

### 7. 검증과 보안

자동화가 돌아간 뒤에는 결과물이 제대로 만들어졌는지 확인하고, API 키가 코드에 노출되지 않았는지 점검한다. 영상은 자동화보다 보안과 검토 책임이 더 중요하다고 강조한다.

## 바로 따라 할 체크리스트

- 반복 업무 하나를 고른다.
- 목표, 입력, 처리 과정, 출력물을 한 문장씩 적는다.
- VS Code에서 새 프로젝트 폴더를 만든다.
- 클로드 코드에 플랜 모드로 실행 계획을 먼저 요청한다.
- 계획을 검토한 뒤 작은 샘플 데이터로 실행한다.
- 결과를 보고 “다음부터는 이렇게 고쳐줘”라고 피드백한다.
- API 키나 비밀값이 코드에 들어가지 않았는지 확인한다.
