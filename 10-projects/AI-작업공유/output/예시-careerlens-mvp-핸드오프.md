## 목표

커리어 방향이 정해지지 않은 사용자에게 "하는 일" 중심의 업무카드를 보여주고, 사용자가 고른 카드를 군집화해 직무·산업 도메인을 설명 가능하게 추천하는 MVP를 만든다.

## 한 일 / 결정한 것

- 원티드 채용공고 18건을 수집해 업무카드 74개 초안 제작 — 이렇게 정한 이유: 잡코리아·사람인·그리팅은 자동 수집(WebFetch)이 403 차단·JS 렌더링 문제로 막혀서, 안정적으로 읽히는 원티드만으로 우선 진행
- 계산 방식이 다른 버전 4개(v1~v4)를 병행 개발하며 이전 버전은 그대로 보존 — 이렇게 정한 이유: v1(자카드 유사도+분야 보너스, 완전 오프라인) → v2(Sentence-BERT 코사인+공동출현 결합) → v3(코사인 유사도만 사용) → v4(v3 로직 + 도메인 카드)로 실험을 이어가되, 앞 버전과 비교할 수 있게 지우지 않음
- "분야"(직무 카테고리) 축을 "산업 도메인 9개" 축으로 전환, 카드도 74개 → 77개로 재작성 — 이렇게 정한 이유: 실제 목표가 "학생이 관심 산업을 찾는 것"인데 기존 "분야"가 직무 카테고리였고, 편견 제거 과정에서 산업 맥락까지 같이 지워졌던 걸 발견함 (자세한 기준: `notes/도메인-분류-기준-2026-09-02.md`)
- v4를 Playwright로 실제 브라우저에서 검증 완료 — 모델 로딩, 카드 렌더링, 추천 결과, "계산 과정 보기", 도메인 설명 탭까지 콘솔 에러 0건 확인 (카드 조합 1건 기준)
