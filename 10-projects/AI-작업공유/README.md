# AI 작업공유

## 한 줄 목표

BAI 소모임원들이 각자 AI 에이전트로 작업한 맥락을, 회의 없이도 표준화된 문서 한 장으로 서로 넘길 수 있게 만든다.

## 작업 카드

목표: 팀원 간 AI 작업 맥락 공유를 위한 "핸드오프 문서" 템플릿을 만든다
입력: 각자의 AI 작업 세션 (대화 내용, 결정 사항, 결과물 위치)
출력: 재사용 가능한 핸드오프 문서 템플릿(.md) + 작성 예시
성공 기준: 템플릿대로 작성한 문서를 팀원이 읽었을 때, 원본 대화를 안 보고도 "무엇이 끝났고, 뭐가 막혔고, 다음에 뭘 해야 하는지" 파악 가능
오늘 만들 최소 버전: 빈 템플릿 1개 + 작성 예시 1개

## 만들 기능

- [x] 핸드오프 문서 템플릿 (`src/핸드오프-템플릿.md`)
- [x] 템플릿을 실제로 채운 작성 예시 (`output/작성-예시.md`)
- [ ] 팀 공유 저장 위치 정하기 (GitHub repo / Notion / Slack 중 택1)
- [ ] 세션 종료 시 이 템플릿으로 자동 요약해주는 스킬 만들기 (다음 단계)

## 실행 방법

1. `src/핸드오프-템플릿.md`를 복사해서 새 파일을 만듭니다. (예: `output/2026-09-09-크롤링-핸드오프.md`)
2. 대괄호 `[ ]` 부분을 실제 내용으로 채웁니다.
3. 완성된 문서를 팀 공유 위치(정하기 전까지는 카카오톡/디스코드 등)에 올려 팀원에게 전달합니다.
4. 받은 사람은 그 문서를 자기 AI 에이전트 대화창에 붙여넣고 이어서 작업을 요청합니다.

## 확인 방법

`output/작성-예시.md`를 열어서, 원본 대화를 전혀 모르는 사람이 읽어도 "이 사람이 뭘 했고, 다음에 내가 뭘 해야 하는지" 이해되는지 확인합니다.

## Codex에게 다음에 요청할 말

"AI 작업공유 프로젝트에서, 세션이 끝날 때 이 템플릿 형식으로 자동 요약해주는 스킬을 만들어줘."

## 메모

- 원본 대화를 통째로 공유하지 않는 이유: 노이즈가 많아서 상대방 AI가 핵심을 못 고름. 항목별로 걸러낸 요약이 회의보다 효율적임.
- 다음 단계 후보: (1) 팀 공유 저장 위치 확정, (2) 세션 종료 시 자동으로 이 형식으로 요약을 뽑아주는 스킬 제작, (3) AGENTS.md에 "세션 시작 시 최신 핸드오프 문서 확인" 규칙 추가.
