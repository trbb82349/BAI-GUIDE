# 2026-07-18 작업 기록 — 문서 규칙 정리와 AGENTS.md 설명

## 오늘 한 일 요약

워크스페이스 문서화 규칙 두 가지(프로젝트별 "사용된 컴퓨터 지식/스킬" 노트, 스킬별 "쉽게 설명" 파일)를 새로 만들고, 실제 프로젝트/스킬에 적용했다. 그리고 AGENTS.md·CLAUDE.md의 역할과 내용을 여러 번에 걸쳐 쉬운 말로 설명받았다.

## 요청한 것 → 한 것 (시간순)

1. **AGENTS.md 파일이 뭔지 설명해줘**
   → AGENTS.md는 워크스페이스 공통 작업 규칙 파일이고, CLAUDE.md는 그걸 그대로 가져와 쓴다는 구조를 설명받음.

2. **`10-projects/작업이름/src/` 폴더의 `src`가 무슨 약자인지**
   → "source"(소스 코드)의 줄임말이라는 설명을 받음.

3. **`notes/` 폴더에 프로젝트 진행할 때마다 "컴퓨터 지식/스킬을 비전공자 눈높이로 설명하는 md 파일"을 추가로 만들어달라는 규칙 요청**
   → `.codex/rules/build-workflow.md`와 `.codex/references/notes-learning-guide.md`를 새로 만들어 규칙화. (처음엔 "학습노트"라는 이름 → 이후 요청으로 "사용된 컴퓨터 지식/스킬"로 명칭 변경, 파일명에서 날짜도 제거)
   → 이후 "새 프로젝트든 이어서 하는 프로젝트든, 새로 쓰인 지식/스킬이 있으면 기존 파일을 계속 업데이트"하는 방식으로 규칙을 한 번 더 다듬음(파일을 매번 새로 만들지 않고 이어서 갱신).

4. **china-trend-tracker 프로젝트에 위 규칙에 따른 예시 파일 요청**
   → 프로젝트 코드(collect.py, build_site.py, update.yml, setup-guide.md)를 분석해 `10-projects/china-trend-tracker/notes/사용된-컴퓨터-지식-스킬-전체정리.md` 생성. (외부 API 호출, 프롬프트 작성, JSON 저장, Python 자동화, 자동 HTML 생성, GitHub Actions, GitHub Secrets, GitHub Pages 등 정리)

5. **부루마블 프로젝트에도 같은 파일 요청**
   → 코드(부루마블.html, README.md, rules.md)를 분석해 `10-projects/burumabeul/notes/사용된-컴퓨터-지식-스킬-전체정리.md` 생성. (한 파일 완결형 웹앱, CSS Grid, CSS로 국기 그리기, CSS 3D 애니메이션, Web Audio API, async/await, render() 상태 갱신, NPC 로직, Node.js 시뮬레이션 검증 등 정리)

6. **`.agents/skills/`의 SKILL.md 파일들(docx, pdf, pptx, xlsx, web-scraper, skill-creator, bai-feed-goodbai, auto-update-site)이 각각 뭔지 설명 요청**
   → 각 스킬의 용도를 한 줄씩 정리해 설명.

7. **위 스킬 파일들에도 "스킬 쉽게 설명" md 파일을 만들어달라는 규칙 요청 (docx 예시로 먼저 생성)**
   → `.codex/rules/skills-plain-explanation.md` 규칙 신설, AGENTS.md 스킬 표 아래에 안내 문구 추가. `docx/스킬-쉽게-설명.md` 생성.

8. **나머지 스킬들도 동일 형식으로 요청**
   → pdf, pptx, xlsx, web-scraper, skill-creator, bai-feed-goodbai, auto-update-site 총 7개 `스킬-쉽게-설명.md` 파일을 각 SKILL.md 원문 분석 후 생성.

9. **AGENTS.md가 워크스페이스에 1개만 있고 모든 프로젝트에 공통 적용되는지 질문**
   → 루트에만 존재하며, `10-projects/` 하위 모든 프로젝트에 공통 적용되는 최상위 규칙이라고 설명(비유: "워크스페이스 사규" vs 프로젝트별 README는 "부서 매뉴얼").

10. **AGENTS.md 내용을 비전공자 눈높이로 설명 요청**
    → 파일의 목적, 워크스페이스 성격, 작업 전 4가지 확인(목표/입력/출력/확인), 폴더 5단계 구조, 새 프로젝트 틀, 대화 방식, 슬래시 명령, 보안 원칙, 준비된 스킬들을 쉬운 말로 정리해 설명.
