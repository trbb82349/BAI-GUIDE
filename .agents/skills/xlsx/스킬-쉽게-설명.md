# xlsx 쉽게 설명

## 이 스킬은 무엇을 해주나요?

엑셀(.xlsx), CSV 같은 표 형식 파일을 만들거나 읽거나 고쳐주는 도구입니다. 데이터 정리, 새 열 추가, 수식 계산, 서식 꾸미기, 지저분한 데이터를 깔끔한 표로 바꾸는 작업 등을 담당합니다. 특히 재무·회계용 엑셀을 만들 때 지켜야 하는 "전문가들의 색깔 규칙"(입력값은 파란 글씨, 계산식은 검은 글씨 등)까지 알고 있습니다.

## 언제 자동으로 켜지나요?

아래처럼 말하면 자동으로 켜집니다.

- "이 엑셀 파일에 열 추가해줘 / 수식 넣어줘"
- "이 CSV 파일 정리해서 엑셀로 만들어줘"
- "다운로드 폴더에 있는 xlsx 파일 좀 손봐줘"
- "이 데이터로 표/차트 만들어줘"

반대로 결과물이 워드 문서나 HTML 보고서, 독립 실행 파이썬 스크립트일 때는 켜지지 않습니다(표 데이터를 다루더라도 최종 결과물이 엑셀 파일이 아니면 다른 방식으로 처리).

## 이 스킬이 왜 필요한가요?

엑셀 파일은 단순히 숫자를 나열하는 게 아니라, 수식·색깔·서식이 서로 얽혀 있어서 사람이 손으로 하나하나 채우면 시간이 오래 걸리고 실수(수식 오류, 잘못된 참조)가 나기 쉽습니다. 이 스킬은 "숫자를 미리 계산해서 그냥 박아넣지 않고, 엑셀이 스스로 계산하는 수식으로 넣어야 한다"는 원칙을 지켜서, 원본 데이터가 바뀌면 표도 자동으로 다시 계산되는 살아있는 엑셀을 만듭니다. 또한 만든 뒤에는 반드시 재계산 검사를 돌려서 `#REF!`, `#DIV/0!` 같은 수식 오류가 하나도 없는지 자동으로 확인합니다.

## 이 스킬 안에 나오는 용어 쉽게 풀이

- **pandas**: 표 데이터를 빠르게 읽고, 정리하고, 통계 내는 도구(라이브러리). 데이터 분석에 강합니다.
- **openpyxl**: 엑셀 특유의 기능(수식, 색깔, 셀 서식, 열 너비 등)을 세밀하게 다루는 도구.
- **수식(Formula)**: `=SUM(B2:B9)`처럼 "이 셀들의 합을 계산해라" 같은 엑셀 전용 계산 명령. 파이썬에서 미리 계산한 숫자를 박아넣는 대신, 이 수식 자체를 셀에 넣어서 원본 데이터가 바뀌면 자동으로 다시 계산되게 만듭니다.
- **수식 재계산(recalc)**: 셀에 수식 글자만 넣으면 실제 계산된 값이 바로 안 보이는 경우가 있어서, 무료 프로그램(LibreOffice)으로 한 번 열어서 실제 계산을 돌리고 결과값까지 채워 넣는 과정.
- **수식 오류들**: `#REF!`(참조가 잘못됨), `#DIV/0!`(0으로 나눔), `#VALUE!`(엉뚱한 형식의 값), `#NAME?`(모르는 함수 이름) 등, 엑셀이 수식을 계산하지 못했을 때 보여주는 오류 표시.
- **색상 코딩 규칙**: 재무 모델(회사 실적표 같은 것)을 만들 때, 파란 글씨=직접 입력한 숫자, 검은 글씨=계산식, 초록 글씨=다른 시트에서 가져온 값, 빨간 글씨=다른 파일에서 가져온 값처럼 색깔로 셀의 성격을 구분하는 업계 관행.

## 사용할 때 알아두면 좋은 점

- 완성된 파일은 반드시 재계산 검사를 거쳐 수식 오류가 없는지 확인한 뒤 전달됩니다.
- 이미 정해진 회사 양식(템플릿)이 있으면, 새로운 서식 규칙을 강요하지 않고 기존 양식을 그대로 따릅니다.
- 숫자에 단위(예: "매출 (백만 원)")를 항상 헤더에 표시해서 오해를 줄입니다.
- 큰 파일을 다룰 때는 필요한 열/행만 골라서 읽는 방식을 써서 속도를 확보합니다.
