# pdf 쉽게 설명

## 이 스킬은 무엇을 해주나요?

PDF 파일을 다루는 온갖 작업을 대신해주는 도구입니다. PDF에서 글자·표 뽑아내기, 여러 PDF 합치기, 한 PDF를 여러 장으로 쪼개기, 페이지 돌리기, 워터마크(반투명 도장 표시) 넣기, 새 PDF 만들기, 비밀번호 걸기/풀기, 스캔한 종이 문서를 검색 가능한 글자로 바꾸기(OCR)까지 처리합니다.

## 언제 자동으로 켜지나요?

아래처럼 말하면 자동으로 켜집니다.

- "이 PDF에서 표만 뽑아줘"
- "이 두 PDF 파일 하나로 합쳐줘"
- "이 PDF 페이지 좀 돌려줘 / 나눠줘"
- "이 PDF에 비밀번호 걸어줘"
- "스캔한 PDF인데 글자 검색이 안 돼, 검색되게 해줘"
- "이 내용으로 PDF 만들어줘"

## 이 스킬이 왜 필요한가요?

PDF는 워드 문서와 달리 "고정된 그림처럼 찍혀 나온 문서"에 가까워서, 사람이 내용을 복사하거나 표를 뽑아내려 하면 줄바꿈이 깨지거나 표 모양이 무너지는 경우가 많습니다. 이 스킬은 PDF 내부 구조를 정확히 읽는 전용 도구들을 알고 있어서, 표는 표대로, 글자는 글자대로 깔끔하게 뽑아내고, 여러 PDF를 순서대로 이어 붙이거나 자르는 작업도 한 번에 처리합니다. 스캔된 이미지뿐인 PDF(글자를 마우스로 선택할 수 없는 문서)도 사진 속 글자를 인식해서 검색 가능한 문서로 바꿔줍니다.

## 이 스킬 안에 나오는 용어 쉽게 풀이

- **pypdf**: PDF 페이지를 합치거나 나누거나 돌리는 등 기본적인 조작을 해주는 도구(라이브러리).
- **pdfplumber**: PDF 안의 글자와 표를 원래 배치 그대로 정확히 뽑아내는 도구. 특히 표가 있는 PDF에서 유용합니다.
- **reportlab**: 아무것도 없는 상태에서 새 PDF를 처음부터 만들어주는 도구.
- **OCR (광학 문자 인식)**: 스캔된 종이 사진처럼 "그림"으로만 되어 있는 문서에서, 그림 속 글자 모양을 인식해 실제 글자(복사·검색 가능한 텍스트)로 바꿔주는 기술입니다.
- **워터마크**: 문서 위에 겹쳐 보이는 반투명 로고나 "초안", "기밀" 같은 표시. 다른 PDF를 겹쳐 그리는 방식으로 넣습니다.
- **qpdf / pdftk**: 명령어 한 줄로 PDF를 합치거나 자르거나 회전시킬 수 있는 별도 도구들. pypdf로 안 될 때 대안으로 씁니다.
- **PDF 양식(Form) 채우기**: PDF 안에 만들어진 입력칸(이름, 날짜 등)에 자동으로 값을 채워 넣는 기능.

## 사용할 때 알아두면 좋은 점

- 표가 많은 PDF는 표 추출 결과를 한 번 확인하는 게 좋습니다. PDF 원본이 복잡하게 디자인되어 있으면 표 경계가 어긋날 수 있습니다.
- 스캔 문서 OCR은 화질이 나쁘면 인식률이 떨어질 수 있습니다.
- 비밀번호가 걸린 PDF를 풀 때는 반드시 사용자가 알려준 비밀번호로만 진행하며, 비밀번호를 파일이나 기록에 남기지 않습니다.
- 새 PDF를 만들 때 첨자(아래·위 첨자, 예: H₂O)는 특수 기호를 직접 쓰지 않고 별도 표시 방법을 씁니다. 안 그러면 까맣게 뭉개져 보일 수 있기 때문입니다.
