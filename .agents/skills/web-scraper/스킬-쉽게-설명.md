# web-scraper 쉽게 설명

## 이 스킬은 무엇을 해주나요?

웹사이트에서 원하는 정보(기사 제목, 상품 목록, 게시글 등)를 자동으로 긁어오는 프로그램(크롤러/스크래퍼)을 대신 만들어주는 도구입니다. 사이트 구조를 먼저 살펴본 뒤, 그 구조에 맞는 수집 스크립트를 자동으로 짜줍니다.

## 언제 자동으로 켜지나요?

아래처럼 말하면 자동으로 켜집니다.

- "크롤러 짜줘"
- "이 사이트 데이터 수집해줘"
- "스크래핑 코드 만들어줘"
- "이 웹페이지 내용 긁어와줘"

이 스킬은 다른 방법(직접 URL을 하나씩 가져오는 방식)보다 항상 먼저 시도되도록 정해져 있습니다.

## 이 스킬이 왜 필요한가요?

웹사이트는 저마다 구조가 다릅니다. 어떤 사이트는 단순한 정적 페이지라 내용을 바로 읽을 수 있고, 어떤 사이트는 화면이 자바스크립트로 나중에 그려지는 동적 페이지라 실제 브라우저처럼 접속해야만 내용이 보입니다. 이 스킬은 먼저 "가장 가벼운 방법"(그냥 페이지 내려받기, 또는 RSS 피드)부터 시도하고, 그걸로 안 되는 경우에만 "무거운 방법"(진짜 브라우저를 띄워서 살펴보기)으로 넘어가도록 순서를 정해줍니다. 사람이 매번 사이트 구조를 분석해서 코드를 새로 짜는 대신, 이 스킬이 구조를 스스로 탐색하고 그에 맞는 수집 코드를 자동 생성해줍니다.

또한 "이 사이트를 자동으로 긁어가도 되는지"를 미리 확인하는 절차(robots.txt 확인)를 반드시 거치고, 애매하면 사용자에게 먼저 물어봅니다.

## 이 스킬 안에 나오는 용어 쉽게 풀이

- **크롤링/스크래핑**: 사람이 웹페이지를 하나하나 읽으며 정보를 옮겨 적는 대신, 프로그램이 자동으로 웹페이지를 방문해서 원하는 정보만 뽑아오는 것.
- **정적 HTML**: 페이지를 열자마자 이미 완성된 상태로 보이는 웹페이지. 이런 페이지는 그냥 내려받기만 해도 내용을 읽을 수 있습니다.
- **RSS/Atom(피드)**: 뉴스 사이트나 블로그가 "새 글 목록"을 컴퓨터가 읽기 좋은 형식으로 따로 제공하는 것. 있으면 가장 안정적이고 빠른 수집 방법입니다.
- **BeautifulSoup**: 정적 HTML 안에서 원하는 부분(제목, 링크 등)만 골라내는 도구(라이브러리).
- **동적 페이지 / SPA**: 페이지를 열었을 때 처음엔 비어 있다가, 자바스크립트가 실행되면서 내용이 뒤늦게 채워지는 웹페이지. 이런 페이지는 그냥 내려받기만 해서는 내용이 안 보입니다.
- **Playwright**: 진짜 브라우저를 컴퓨터가 대신 조작하게 해주는 도구. 동적 페이지에서 버튼을 클릭하거나 스크롤을 내리는 것까지 자동으로 흉내 낼 수 있습니다.
- **셀렉터(selector)**: "이 페이지에서 정확히 어느 부분이 제목이고 어느 부분이 목록인지"를 가리키는 주소 같은 것. 이 스킬은 이걸 자동으로 찾아냅니다.
- **robots.txt**: 웹사이트 운영자가 "여기는 자동 수집해도 되고, 여기는 안 된다"를 적어둔 규칙 파일. 이 스킬은 이 규칙을 먼저 확인하고, 금지된 것 같으면 진행 전에 반드시 사용자에게 위험(저작권, 약관 위반 등)을 알리고 동의를 구합니다.

## 사용할 때 알아두면 좋은 점

- 작업 전에 "어느 영역을, 목록만 할지 상세페이지까지 할지, 몇 개나, 어떤 파일 형식으로" 같은 질문을 먼저 받습니다. "알아서 해줘"라고 답하면 안전한 기본값(전체 탐색, 목록만, 10개, Markdown)으로 진행됩니다.
- robots.txt에서 경고가 뜨면 절대 마음대로 진행하지 않고, 위험성을 설명한 뒤 사용자의 동의를 받은 뒤에만 계속합니다.
- 로그인이 필요하거나 캡차(사람인지 확인하는 퍼즐)가 있는 사이트는 자동 수집이 막힐 수 있습니다.
- 결과 파일은 기본적으로 `30-inbox/web/` 폴더에 JSON, CSV, Markdown 중 원하는 형식으로 저장됩니다.
