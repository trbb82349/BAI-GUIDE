# docx 쉽게 설명

## 이 스킬은 무엇을 해주나요?

Word 문서(.docx 파일)를 대신 만들어주거나, 이미 있는 워드 파일을 읽고 고쳐주는 도구입니다. 보고서, 메모, 편지, 계약서 초안처럼 "워드로 만들어줘"라고 하는 결과물을 이 스킬이 담당합니다.

## 언제 자동으로 켜지나요?

아래처럼 말하면 자동으로 켜집니다.

- "이거 워드 문서로 만들어줘"
- "이 .docx 파일 내용 읽어줘 / 요약해줘"
- "이 워드 파일에서 이 단어를 저 단어로 다 바꿔줘"
- "표지, 목차, 페이지 번호 있는 보고서 만들어줘"
- "이 워드 파일에 있는 이미지 바꿔줘"

반대로 PDF나 엑셀, 구글 문서를 다룰 때는 켜지지 않습니다(각각 다른 스킬이 담당).

## 이 스킬이 왜 필요한가요?

워드 파일(.docx)은 사실 겉모습만 문서일 뿐, 속은 압축된 폴더(ZIP)이고 그 안에 문서 내용을 표현하는 XML이라는 코드가 들어있습니다. 사람이 워드 프로그램을 직접 열어서 하나하나 클릭하며 표를 만들고 목차를 넣고 서식을 맞추는 대신, 이 스킬은 그 내부 구조를 이해하고 있어서 코드로 한 번에 정확하게 만들어 줍니다. 특히 "목차, 페이지 번호, 각주, 여러 단 나누기" 같은 복잡한 서식은 사람이 손으로 하면 오래 걸리는데, 정해진 규칙대로 코드로 처리하면 훨씬 빠르고 실수도 적습니다.

## 이 스킬 안에 나오는 용어 쉽게 풀이

- **.docx = 압축 폴더**: 워드 파일은 사실 ZIP처럼 압축된 폴더입니다. 그 안에 글자, 표, 이미지 정보가 XML(컴퓨터가 읽는 문서 설계도) 형태로 나뉘어 저장돼 있습니다.
- **XML**: 사람이 쓰는 문장이 아니라, "이 글자는 몇 포인트, 이 단어는 굵게" 같은 규칙을 컴퓨터가 알아보게 적어놓은 표시 언어입니다. HTML과 비슷한 형태입니다.
- **pandoc**: 워드 파일 내용을 사람이 읽기 쉬운 글(Markdown)로 뽑아내는 변환 도구. "이 워드 파일에 뭐라고 써있어?"를 확인할 때 씁니다.
- **docx-js**: 새 워드 파일을 처음부터 만들 때 쓰는 코드 도구(라이브러리). "제목은 이렇게, 표는 이렇게" 하고 재료를 코드로 나열하면 워드 파일을 조립해 줍니다.
- **DXA**: 워드 문서 안에서 길이(간격, 여백, 표 너비 등)를 재는 단위입니다. 1440 DXA = 1인치라고 정해져 있어서, 이 숫자로 여백이나 표 크기를 정확히 맞춥니다.
- **Unpack → Edit XML → Pack (풀기 → 고치기 → 다시 묶기)**: 이미 있는 워드 파일을 고칠 때 쓰는 3단계 방법입니다. 압축을 풀어서 안의 XML 코드를 직접 고친 다음, 다시 압축해서 워드 파일로 만듭니다.
- **Tracked Changes (변경 내용 추적)**: 워드에서 "누가 뭘 지우고 뭘 더했는지" 색깔로 표시해주는 기능. 이 스킬은 사람이 검토하기 편하게 삭제/추가 표시를 넣을 수 있습니다.
- **Table of Contents (목차)**: 문서 제목들을 자동으로 모아서 페이지 번호와 함께 보여주는 목차를 자동 생성할 수 있습니다.
- **LibreOffice**: 워드 파일을 PDF나 이미지로 변환할 때 뒤에서 쓰는 무료 오피스 프로그램입니다.

## 사용할 때 알아두면 좋은 점

- 완성된 워드 파일은 자동으로 한 번 검증(문제 없는지 확인)까지 거칩니다.
- "표지·목차·페이지 번호 있는 보고서" 같은 구체적인 요청일수록 결과물이 더 깔끔하게 나옵니다.
- 이미 있는 파일을 고칠 때는 원본 서식(글씨체, 굵기 등)을 최대한 그대로 유지하도록 설계돼 있습니다.
- 오래된 `.doc`(구버전 워드) 파일은 먼저 `.docx`로 변환한 뒤에 처리됩니다.
