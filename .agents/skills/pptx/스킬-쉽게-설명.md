# pptx 쉽게 설명

## 이 스킬은 무엇을 해주나요?

PowerPoint 슬라이드(.pptx 파일)를 만들거나 읽거나 고쳐주는 도구입니다. 발표 자료, 피치덱(투자 설명용 슬라이드), 강의 자료처럼 "슬라이드로 만들어줘"라고 하는 결과물을 담당하고, 색깔·글꼴·레이아웃까지 신경 써서 "그냥 텍스트만 있는 심심한 슬라이드"가 되지 않도록 디자인 규칙도 갖고 있습니다.

## 언제 자동으로 켜지나요?

아래처럼 말하면 자동으로 켜집니다.

- "발표 자료(덱) 만들어줘"
- "이 .pptx 파일 내용 읽어줘 / 요약해줘"
- "이 슬라이드 파일 좀 고쳐줘 / 업데이트해줘"
- "이 템플릿으로 슬라이드 만들어줘"
- 파일 확장자가 .pptx인 걸 다루는 모든 상황

## 이 스킬이 왜 필요한가요?

PowerPoint는 텍스트 상자, 도형, 이미지, 색깔, 글꼴 크기가 한 슬라이드 안에 다 같이 얽혀 있어서, 사람이 하나하나 마우스로 배치하면 시간이 오래 걸리고 슬라이드마다 디자인이 들쭉날쭉해지기 쉽습니다. 이 스킬은 "제목은 이 정도 크기, 본문과 배경은 이 정도 대비를 유지해야 한다" 같은 전문 디자이너의 규칙(색상 배합, 여백, 글꼴 궁합)을 이미 알고 있어서, 처음부터 통일감 있는 결과물을 만들어줍니다. 게다가 다 만든 뒤 슬라이드를 이미지로 변환해서 "글자가 잘렸는지, 요소가 겹쳤는지"까지 스스로 검사하는 과정도 포함되어 있습니다.

## 이 스킬 안에 나오는 용어 쉽게 풀이

- **markitdown**: .pptx 파일 안의 글자 내용만 쭉 뽑아서 보여주는 도구. "이 발표자료에 뭐라고 써있어?"를 확인할 때 씁니다.
- **pptxgenjs**: 슬라이드를 처음부터 코드로 만들 때 쓰는 도구(라이브러리). 재료(제목, 표, 이미지 등)를 코드로 지정하면 슬라이드 파일을 조립해줍니다.
- **템플릿 기반 편집**: 이미 만들어진 슬라이드 파일(회사 양식 등)을 열어서 내용만 바꾸는 방식. 원래 디자인을 최대한 유지합니다.
- **색상 팔레트**: 슬라이드 전체에서 쓰는 색깔 조합 세트. 주제와 어울리는 조합(예: 어두운 남색+아이스블루)을 미리 정해두고 일관되게 사용합니다.
- **대비(Contrast)**: 글자색과 배경색의 밝기 차이. 차이가 작으면 글자가 잘 안 보이므로, 항상 눈에 띄는 정도의 차이를 유지하도록 점검합니다.
- **QA(품질 검사) 과정**: 완성된 슬라이드를 이미지로 변환해서, 글자가 잘리거나 요소가 겹치거나 여백이 부족한 곳이 없는지 다시 한번 눈으로 확인하는 검증 단계.
- **LibreOffice / Poppler**: 슬라이드 파일을 PDF나 이미지로 변환해주는 무료 프로그램들. 최종 검사 단계에서 씁니다.

## 사용할 때 알아두면 좋은 점

- 텍스트만 나열된 슬라이드는 지양하고, 이미지나 아이콘, 도표 같은 시각 요소를 매 슬라이드에 넣도록 신경 씁니다.
- 완성 후 최소 한 번은 이미지로 변환해 눈으로 검사하는 과정을 거치므로, 결과물을 받으면 실제로 열어서 확인하는 게 좋습니다.
- 회사 양식(템플릿)이 있으면 그 틀을 최대한 유지하며 내용만 바꿔줍니다.
- "제목 아래 줄 긋기" 같은 특정 장식은 일부러 피합니다. AI가 만든 티가 나는 흔한 패턴이기 때문입니다.
