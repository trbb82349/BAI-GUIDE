# bai-feed-goodbai 쉽게 설명

## 이 스킬은 무엇을 해주나요?

오늘 한 작업을 정리해서 BAI 학생 피드(진행 상황을 공유하는 웹페이지)에 자동으로 올려주는 도구입니다. "오늘 한 일 / 배운 것 / 막힌 점" 세 가지만 답하면, 나머지(태그, 관련 링크 등)는 AI가 대화와 작업 내용을 보고 알아서 정리해서 올려줍니다.

## 언제 자동으로 켜지나요?

- `/goodbai` 명령을 실행할 때
- "BAI 피드에 진행 보고 올려줘" 같은 요청을 할 때

## 이 스킬이 왜 필요한가요?

매번 진행 보고를 쓸 때마다 "오늘 뭐 했지, 태그는 뭘로 하지, 링크는 어디 있지" 하나하나 정리하는 건 번거롭습니다. 이 스킬은 사람에게는 딱 3가지 쉬운 질문만 하고, 나머지 정리(태그 붙이기, 관련 링크 찾기)는 AI가 작업 맥락을 보고 대신 채웁니다. 또한 실수로 잘못된 내용이 올라가지 않도록, 실제로 전송하기 전에 "미리보기(dry-run)"로 한 번 확인하고, 사용자가 최종 확인해야만 진짜로 전송됩니다.

## 이 스킬 안에 나오는 용어 쉽게 풀이

- **피드(Feed)**: 여러 학생들의 진행 상황이 시간순으로 모여 보이는 게시판 같은 웹페이지.
- **dry-run(드라이런, 미리보기)**: 실제로 전송하지 않고, "이렇게 전송될 예정입니다"라는 내용만 미리 보여주는 연습 실행. 잘못 올라가는 걸 막아줍니다.
- **API 키**: 이 프로그램이 "나는 진짜 이 학생이 맞다"는 걸 증명하는 비밀 값(비밀번호와 비슷한 개념). 선생님에게 받아서 한 번 등록해두면 계속 씁니다.
- **태그(tag)**: 게시물을 분류하는 짧은 꼬리표(예: "파이썬", "웹사이트"). 검색하거나 모아볼 때 씁니다.
- **payload(전송 내용)**: 실제로 서버에 보내지는 데이터 묶음. 이 스킬에서는 한 일/배운 것/막힌 점/태그/링크가 여기 담깁니다.
- **401 오류 / 로그인 실패**: 등록해둔 API 키가 틀렸거나 만료됐을 때 나는 오류. 이 경우 설정을 다시 등록해야 합니다.

## 사용할 때 알아두면 좋은 점

- 처음 사용할 때는 BAI 계정 설정(이름 + API 키 등록)이 한 번 필요합니다. 이후에는 다시 안 해도 됩니다.
- API 키나 비밀번호 같은 값은 화면에 그대로 보이지 않도록 입력하며, 절대 대화나 파일에 노출하지 않습니다.
- 전송 전 항상 최종 내용을 보여주고 확인을 받으므로, 마음에 안 들면 전송 전에 수정을 요청할 수 있습니다.
- 막힌 점이 정말 없다면 "없음"이라고 답하면 되고, 빈 칸으로 두면 전송되지 않습니다.
