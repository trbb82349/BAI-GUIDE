# skills-plain-explanation.md — 스킬 쉬운 설명 파일 규칙

## 목적

`.agents/skills/`의 각 스킬 폴더에는 SKILL.md(에이전트가 읽는 기술 설명) 외에, 컴퓨터 지식이 없는 사람도 "이 스킬이 뭘 해주는 도구인지" 이해할 수 있는 쉬운 설명 파일을 같이 둡니다.

## 적용 시점

- 새 스킬을 `.agents/skills/`에 추가할 때
- 기존 스킬의 SKILL.md 내용이 크게 바뀔 때 (새 기능·도구 추가 등)

## 파일 위치와 이름

`.agents/skills/스킬이름/스킬-쉽게-설명.md` (SKILL.md와 같은 폴더, 날짜 없음)

## 새로 만들지 vs 업데이트할지

1. 먼저 해당 스킬 폴더에 이 파일이 이미 있는지 확인합니다.
2. 있으면: SKILL.md에서 새로 추가되거나 바뀐 내용만 이어서 반영합니다. 이미 맞는 내용은 다시 쓰지 않습니다.
3. 없으면: 새로 만듭니다.

## 대상 독자

컴퓨터 지식이나 개발 용어를 전혀 모르는 사람. 전문 용어는 쓰지 않거나, 쓰더라도 바로 쉬운 말로 풀어줍니다.

## 필수 섹션

```markdown
# (스킬 이름) 쉽게 설명

## 이 스킬은 무엇을 해주나요?
(한 줄 요약, 비유를 써도 좋음)

## 언제 자동으로 켜지나요?
(트리거 조건을 쉬운 말로. "이런 말을 하면 자동으로 실행됩니다" 식으로)

## 이 스킬이 왜 필요한가요?
(이 스킬이 없으면 사람이 직접 무엇을 얼마나 번거롭게 해야 하는지 비교)

## 이 스킬 안에 나오는 용어 쉽게 풀이
- 용어: 쉬운 설명

## 사용할 때 알아두면 좋은 점
-
```

## 작성 기준

- SKILL.md 안의 기술 용어(라이브러리 이름, 파일 형식, 명령어 등)를 골라 일상 언어로 풀어씁니다.
- 전문 용어는 처음 나올 때 옆에 괄호로 짧은 뜻을 바로 붙입니다. (예: CSS(웹페이지 색깔·글씨체·배치를 꾸미는 코드), 렌더링(화면에 실제로 그려지는 것))
- 코드나 명령어 자체를 그대로 옮기지 말고, "이게 어떤 역할을 하는지"만 설명합니다.
- 실제 트리거 문장(사용자가 어떻게 말하면 켜지는지) 예시를 넣어 "아, 이럴 때 쓰는 거구나"를 바로 알 수 있게 합니다.
